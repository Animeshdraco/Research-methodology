# Overleaf screen recording and Google Drive submission

This recording must be made by the student from their own Overleaf session; it is not included in the source archive.

1. Create a new Overleaf project and upload the files from the `overleaf/` folder in the submission bundle.
2. Set `Main.tex` as the main document and compile it with pdfLaTeX.
3. Start a screen recording using Windows Snipping Tool screen recording, Xbox Game Bar (`Win + Alt + R`) or OBS.
4. In one continuous recording, show the Overleaf project title, the `Main.tex` source, the successful compiled PDF, and the project file tree. Briefly scroll through the title/abstract, methodology, results and references so the recording demonstrates that the paper source compiles.
5. Stop recording and save the MP4 with a clear filename, such as `Nischal_JalRakshak_Overleaf_Record.mp4`.
6. Upload that MP4 to Google Drive.
7. Open Share settings, change General access to **Anyone with the link**, set the role to **Viewer**, save, and copy the link.
8. Open the link in a private/incognito browser window to check that it can be viewed without signing in.
9. Paste the verified Drive URL into the submission form and keep a copy in your own records.

Do not include passwords, access tokens or private account information in the recording.
