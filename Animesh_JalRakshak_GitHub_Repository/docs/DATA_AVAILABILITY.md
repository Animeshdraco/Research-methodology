# Code and research-data availability

## Dataset

`analysis/data/simulated_readings.csv` is generated by `analysis/scripts/01_generate_data.py` using seed 42. It contains 504 hourly records: 168 hours each for three illustrative device/location scenarios (Dhanbad, West Singhbhum and Ramgarh). No observations were collected from a river, mine, borewell, household, treatment plant or laboratory. All concentrations, treatment removal efficiencies, sensor noise and fault events are model assumptions. The file includes `data_source=simulated` and injected-event labels.

The SQLite database is rebuilt by `backend/seed_demo.py --replace` from that CSV and is ignored by Git; it is generated at run time. When accessed through FastAPI, the dashboard uses the API-fed SQLite records. Both online and offline preview modes are labelled as simulated.

## Source code

This repository provides the API, schemas, device-key authentication, SQLite storage, alert rules, synthetic dataset generator, forecast/anomaly experiments, sensitivity sweep, automated tests, interactive dashboard source, and an ESP32 integration template. The full reproducibility command is `./run_all.sh`; local web execution is `./start_local.sh`. The firmware has not been compiled or flashed in this environment.

## Availability statement for the paper

The source code, seeded synthetic dataset and experiment outputs are included in the accompanying repository. The dataset was generated for software testing and contains no real-world water measurements. No human-subject data or laboratory observations were collected. The database can be recreated locally from the included CSV and seed script.

## Future data publication

Any future field dataset should include probe model and calibration records, timestamp and sampling metadata, site-independent identifiers, laboratory results, methods, quality flags and permission to redistribute. Remove personal data and sensitive household or location details. A GitHub URL must be added only after the student publishes their own repository; this local source archive is not yet a public GitHub release.
