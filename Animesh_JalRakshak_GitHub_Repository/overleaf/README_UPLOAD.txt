OVERLEAF UPLOAD

1. Create a blank Overleaf project.
2. Upload Main.tex and jw03_tds_series.pdf from this folder.
3. Set Main.tex as the main document and use pdfLaTeX.
4. Compile and confirm the PDF displays five pages.
5. Record your own Overleaf session and share that recording through Google Drive using Anyone with the link / Viewer.

The PDF in this folder is a locally compiled reference output. Your submitted screen recording must show the project and compile inside your own Overleaf account.
