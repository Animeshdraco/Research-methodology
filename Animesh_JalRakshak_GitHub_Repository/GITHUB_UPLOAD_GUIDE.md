# GitHub upload guide — Animesh Giri

This ZIP is a prepared repository folder. GitHub's normal web upload does not accept a ZIP as a repository import. Extract the ZIP, open `Animesh_JalRakshak_GitHub_Repository`, create a new empty GitHub repository under the student's account, and upload the folder's contents. Do not upload the outer ZIP as a single file.

The package intentionally excludes the separate individual contribution statement and personal dashboard JPG screenshot. All application source, test files, research data, paper and presentation files required for this repository are included.
